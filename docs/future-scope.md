# LearnSphere LMS — Post-MVP Future Scope Roadmap

## 1. Automated PDF Certificate Generation
- **Concept**: Upon a student reaching 100% course progress and passing all course quizzes, the system automatically signs and generates a verifiable PDF certificate with a cryptographic QR code.
- **Technologies**: `pdfkit`, `qrcode`, digital signature hashes.

## 2. Integrated Payment Gateway
- **Concept**: Allow instructors to monetize premium curriculums via one-time tuition fees or monthly student subscriptions.
- **Technologies**: Stripe API with webhook verification and multi-currency billing.

## 3. WebRTC Live Virtual Classrooms
- **Concept**: Real-time instructor lectures, screen sharing, student audio/video, and interactive digital whiteboards.
- **Technologies**: WebRTC, Socket.io, MediaSoup.

## 4. Discussion Forums & Lesson Annotation
- **Concept**: Collaborative Q&A threads attached directly beneath specific lesson timestamps or paragraphs.
- **Technologies**: Markdown threading, upvoting, instructor-endorsed answers.
